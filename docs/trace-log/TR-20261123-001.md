# TR-20261123-001 — CI flake: wall-clock assertion (Windows runner)

> Taxonomy: `FLAKY-TEST` · Severity: 🟡 medium (CI đỏ, code đúng) · Status: ✅ FIXED

## Symptom
Push `94fa56e` (docs-only) → CI run `45102761340` **failure**, chỉ 1 job:
`test (windows-latest, 3.14)`. Run trước (`45102609286`) xanh 5/5 với code gần như y hệt.
macOS + ubuntu PASS cả 2 run → cô lập được ở Windows runner, không phải code.

## Evidence
```
tests\test_e2e.py:128: AssertionError
assert total_elapsed_ms < 1000.0
E  assert 1607.5084209442139 < 1000.0
1 failed, 166 passed in 7.49s
```

## Root cause
`test_full_cognitive_agent_e2e` đo wall-clock toàn pipeline và assert **< 1000ms tuyệt đối**.
Trên shared runner đang tải (Windows run 2), pipeline healthy chạy 1607ms → fail.
Không phải regression — run 1 cùng code PASS. Đây là **assert không tất định**
(biến vào = load máy runner, ngoài tầm kiểm soát test).

## Fix
`tests/test_e2e.py:126-133`: ceiling 1000ms → **10 000ms** (chỉ fail khi thật sự
degrade ~10x, vd O(n²) blowup). Ghi chú giữ mốc sub-second làm reference metric mềm.
Commit: bd219ef.

## Verification
- Local 3.14: 167 passed, ruff clean, mypy 0.
- CI push sau fix: chờ run xanh (đặc biệt Windows).

## Lesson (cho taxonomy `FLAKY-TEST`)
**Không bao giờ assert wall-clock tuyệt đối trong CI** — dùng ceiling gấp 10–20x
target dev-machine, và coi target làm metric quan sát (KPI), không phải gate.
