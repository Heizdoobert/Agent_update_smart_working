# Commitpet

**A Tamagotchi that lives inside your GitHub commit history.**

- Feed it with commits: each push counts as a meal, with code quality (lines, tests added) affecting nutrition value
- Implement mood states (happy, sleepy, sick, feral) driven by commit streaks and repo neglect
- Render it as an animated pixel sprite on a personal web dashboard, with idle animations per mood
- Add a "graveyard" where neglected pets are memorialized with their final commit message as an epitaph
- Optional: pet-to-pet visiting via public repo comparison, letting friends' pets "playdate" based on overlapping commit hours
